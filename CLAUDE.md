# Agent Diff Tracker — agent instructions

VS Code extension that watches the workspace and auto-opens diffs for files an AI agent (or anything else) just changed. Zero runtime dependencies; TypeScript; strict mode.

## Commands

```bash
npm run compile            # tsc build → out/
npm run test:unit          # mocha over test/unit (ts-node, fast)
npm run test:integration   # @vscode/test-electron — real VS Code + generated git fixture
npm test                   # both
npm run reinstall          # build + package + install into local VS Code (user must reload window)
```

## Architecture rules

- **Pure logic lives in dedicated modules** (`matching.ts`, `batchPlan.ts`, `burstHistory.ts`, `firstChange.ts`, `timeAgo.ts`) with no `vscode` import, each covered by unit tests in `test/unit/`. `extension.ts` and `historyProvider.ts` are thin `vscode`-API shells.
- **Every bug fix ships with a test that fails without it.** UI-visible behavior (tab labels, focus, cursor position) is asserted in `test/integration/extension.suite.ts`.
- The integration fixture workspace is **generated by `runTests.ts` on every run** (never committed — an embedded `.git` cannot be tracked).
- No runtime dependencies. Do not add any without explicit maintainer approval.

## Hard-won invariants (do not regress)

- Never use placeholder-string substitution in the glob compiler — patterns containing token-like literal text corrupt (see `matching.ts` single-pass parser + regression tests).
- Never steal-and-restore editor focus to drive diff navigation — restoring focus can hide or replace the diff tab just opened. Aim the cursor via `TextEditor.selection`/`revealRange` on the (possibly unfocused) editor found in `visibleTextEditors`, matched by **full URI including scheme** — the diff's left side (`git:`) shares the same `fsPath`.
- External file changes reach open `TextDocument`s asynchronously and the reload restores prior view state — re-aim on `onDidChangeTextDocument` within a settle window rather than trusting a one-shot write.
- Untracked files diff against the `agent-diff-tracker-empty:` content provider so every open is a labeled diff tab.
- Config values from settings must be clamped (`batchPlan.ts`) — assume users enter garbage.
- `.vscodeignore` must exclude tests, sources, and local tool dirs (`.claude/`, `.impeccable/`); verify `.vsix` contents after packaging changes.

## Releases

Tag `v<version>` after bumping `package.json` + `CHANGELOG.md`; the `release` workflow publishes to the Marketplace (needs `VSCE_PAT` repo secret) and attaches the `.vsix` to a GitHub release. Local installs via `npm run reinstall` are independent of the Marketplace version.
